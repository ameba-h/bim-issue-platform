# 使用手册

> 这一页给**用这个平台的人**看：从登录到导出，每页能做什么、五种人差在哪、哪几步能省鼠标。怎么把平台跑起来看 [快速开始](/guide/getting-started)；本页只管操作，口径备忘放在文末。

## 🚪 第一次登录

1. 用管理员给你的**账号和密码**登录 —— 平台上**没有自助注册**，账号一律由平台管理员开；
2. 左下角头像 →「设置」→「修改密码」，先把初始密码换掉（要填旧密码）；改完当前这次登录仍然有效，不用重新登录；
3. 同一个「设置」页把**姓名和头像**补齐 —— 头像选完自动裁成正方形，不用另开软件；
4. 登录后**什么项目都看不见**：说明还没人把你拉进项目，找项目负责人在「项目设置」的「成员管理」里把你加上。这不是坏了，是真的没数据可看。

⚠️ **忘了密码**：找平台管理员重置。注意重置会把那个人**已登录的所有设备一起下线**，别顺手替别人点。找回密码没有邮件通道 —— 平台不存邮箱，也没有发信的地方。

## 🧭 页面导览

侧栏从上到下（带括号的按身份收放，看不见就是没入口）：

| # | 页面 | 一句话 | 谁能进 |
|---|---|---|---|
| 1 | 首页 | 按类目分组的统计报表：总数 + 四种图（按类型 / 按子项 / 按专业 / 按专项） | 项目成员 |
| 2 | 我的项目 | 我参加的项目（卡片带项目编号与内部编号，点击可复制）+「我提的 / 交给我的」两档 | 项目成员 |
| 3 | 项目说明 | 项目概况 / 经济技术指标 / 各专业设计说明 | 全员可看，负责人与专业负责人可写 |
| 4 | 问题列表 | 干活的主页面：筛选、新建、批量、导出 | 全员可看，能改的按身份分 |
| 5 | （IFC 配置） | 上传这一套模型、看解析走到哪一步 | 负责人 / 专业负责人 / 工程师；**侧栏入口暂不开放**，页面直达可开 |
| 6 | （IFC 画像） | 看模型里有什么：构件数、楼层、类别分布 | 全员可看；**此页开发中**，打开先是空的 |
| 7 | （项目设置） | 项目参数 · 成员管理 · 分类体系 | 仅负责人 / 专业负责人 |
| 8 | （操作记录） | 本项目都改过什么，一条条流水 | 项目成员 |
| 9 | （平台管理） | 建项目、开账号 | 仅平台管理员 |

另有两页不在侧栏：**「设置」**在左下角头像菜单里（管自己）；**「登录」**是唯一不需要身份就能进的页。

**顶栏的项目切换器是全站数据的总开关**：切了项目，所有页面跟着换数据，**你原来填的筛选条件会被清空** —— 这是故意的，那些条件属于上一个项目，留着只会筛出对不上号的结果。切换器里按**项目名称或编号**都能搜，当前项目在最上面，底下那颗「查看全部项目」跳到「我的项目」。

⚠️ **看不见不等于被禁**：界面只是按身份收起入口，真正的把关在服务器那一边 —— 拿别人的页面链接直接贴进地址栏，照样进不去。

## ⌨️ 键盘快捷键

任意页面都能用，**先按一次 `G` 松开，再按字母**：

| 按键 | 去向 | 按键 | 去向 |
|---|---|---|---|
| `G` 然后 `H` | 首页 | `G` 然后 `P` | 项目说明 |
| `G` 然后 `M` | 我的项目 | `G` 然后 `I` | 问题列表 |
| `G` 然后 `S` | 设置 | `G` 然后 `A` | 平台管理（其他人会被拦回并提示） |
| `N` | 操作记录 | `Ctrl` + `K` | 全局搜索与命令面板 |

三条说明：在输入框、文本域里打字**不会误触**；键位是固定配置，暂不支持自定义；字母认的是英文词头，菜单顺序变了键位也不跟着挪。

## 🛡️ 角色与权限

平台上有两套身份，互不相干：一套**全平台**的（普通用户 / 平台管理员），一套**每个项目里**的（负责人 / 专业负责人 / 工程师 / 甲方 / 协同方）。同一个人在 A 项目是负责人，在 B 项目完全可能只是协同方。

| 身份 | 一句话定位 | 典型能做的事 |
|---|---|---|
| 平台管理员 | 管账号和项目本身 | 建项目、开账号、指派负责人、停用账号、重置别人的密码、移交项目负责人 —— 这些都不带来**项目内**权限，他要看某项目的问题，得先被加成那个项目的成员 |
| 项目负责人 | 一个项目的总负责 | 提 / 改 / 删本项目任何问题、改分类和成员、导出、传模型、任命专业负责人 |
| 专业负责人 | 某个专业的负责 | 与项目负责人几乎同权 —— **任命 / 降级专业负责人也能做**；唯一不能的是移交项目负责人（那是平台管理员的动作） |
| 工程师 | 干活的人 | 能提问题、能改**自己提的**、能关自己名下已做完的；不能删、不能换执行人 |
| 甲方 / 协同方 | 外部看的人 | **只能看 + 答复**；配置类页面看不见也进不去 |

### 权限矩阵（问题域）

| 动作 | 项目负责人 | 专业负责人 | 工程师 | 甲方 / 协同方 |
|---|---|---|---|---|
| 查看列表 / 详情 | ✅ | ✅ | ✅ | ✅ |
| 创建问题 | ✅ | ✅ | ✅ | ⛔ |
| 编辑字段 | ✅ 全部 | ✅ 全部 | ⚠️ 仅自己创建的 | ⛔ |
| **答复** | ✅ | ✅ | ✅ | ✅（唯一写入口） |
| 删除问题 | ✅ | ✅ | ⛔ | ⛔ |
| 关闭 / 重开 | ⚠️ 仅当自己是执行人 | ⚠️ 仅当自己是执行人 | ⚠️ 仅当自己是执行人 | ⛔（即便被指为执行人） |
| 变更执行人 | ✅ | ✅ | ⛔ | ⛔ |
| 批量操作 | ✅ | ✅ | ⚠️ 逐条按上述规则判定 | ⛔ |
| 导出 | ✅ | ✅ | ✅ | ⛔ |
| 任命 / 降级专业负责人 | ✅ | ✅ | ⛔ | ⛔ |

要点四句：

- **关闭 / 重开只认「这条问题的执行人是谁」**，跟他是哪个身份无关 —— 负责人不是执行人也关不了；
- **谁提的问题永久记着**：一条问题最初是谁提的，之后无论谁怎么编辑（人还是 AI）都不改这一项；
- **已关闭的问题锁定字段编辑**（唯一例外是变更执行人 —— 那是「改执行人 → 重开 → 再改」既定流程的第一步），但**删除不受限**；
- 项目被**冻结**后（平台管理员操作），成员侧一切写操作（包括答复）一起收掉，看东西不受影响。

前端按钮显隐只是体验层，**服务端逐请求独立校验**才是安全边界。

## 🚶 日常工作流

### 提一条问题

「问题列表」→「新建问题」。表单十项里**真正必填的只有「问题描述」一项** —— 这是刻意的：建模时一句简单描述就能把问题建进来，其余都有兜底、分类允许事后补。

| 项 | 怎么填 |
|---|---|
| 问题描述 | **必填**。**有什么就写什么，口语化也行，不用管格式** —— 一句「12 层走廊风管撞梁了」就能提交。之后**让 AI 按六要素整理**（楼层 → 图纸 → 位置 → 结论 → 详情 → 建议），规范格式是 AI 的活，不是填表人的要求 |
| 类型 / 专业 / 专项 / 子项 | 四个下拉，选项来自**本项目的分类体系**（每个项目独立一套，互不影响），可多选；不填也能提交，之后可由 AI 或负责人补挂 |
| 重要程度 | 四档：紧急 / 普通 / 轻微 / 建议，**不填默认「普通」** |
| 图纸版本 | 收到的图纸上那个日期（形如 2026-09-12）；**这一项为空，这条问题就按「缺位置」计** |
| 轴网定位 | 例如 E-F 轴，可不填；**它为空不算缺** |
| 截图 | **直接把图复制过来按粘贴就行**，不用先建问题再传图 —— 描述没写完也不怕图丢；也能点「选图片」挑文件 |
| 过程附件 | Word / PDF / 图纸 / 压缩包都能带，单个 ≤10 MB、单次最多 6 个，原样存储、只提供下载 |

四条要认的行为：粘贴的图立刻上传；一条问题可以同时挂多个类目；问题编号平台自动排（形如 0007，项目内各自连续、删除后不复用）；**提交后马上能在列表里看到**，没有「待审核」这种状态。

### 跟一条问题走到关闭

在列表里**点那一行的编号**，右侧滑出详情抽屉（不是跳页 —— 这样粘贴截图时手里那条不会丢）。抽屉里有：描述与四个分类 · 重要程度 · 状态 · 执行人 · 提交人和时间 · 截图（点开大图，**左右方向键翻张**）与附件 · 答复时间线（**答复也可以带图**）· 底部操作按钮。

| 动作 | 谁能做 | 注意 |
|---|---|---|
| 答复 | **全员，包括甲方与协同方** | 外部唯一能写的一格；项目冻结时这格也一起收 |
| 改描述 / 分类 / 重要程度 | 负责人、专业负责人；工程师只限自己提的 | 已关闭的要先改执行人并重开才能编辑，按钮旁边有这句话 |
| 变更执行人 | 负责人、专业负责人 | 工程师改不了这一项 —— 这也是「关闭只认执行人」能成立的前提 |
| 关闭 / 重开 | **只认当前执行人** | 关闭是「我这边处理完了」，重开是「还得再来一轮」 |
| 删除 | 负责人、专业负责人 | 已关闭的照样能删；删除是软删可回溯，磁盘文件保留 |

答复**只增不改不删** —— 说错了就再发一条更正。

### 批量操作

多选后可批量改状态 / 改分类 / 改重要程度 / 删除（按角色显隐），单次最多 500 条。动手前可以先预演一遍 —— 不真改，先列出每一条会被改成什么样。提交后**逐条反馈**：成功几条、失败几条、每条为什么失败，部分成功是正常语义。

⚠️ **批量入口只看你的身份，不看具体选中了哪几条**：按钮能点，不代表每一条都改得动（比如工程师勾了别人提的问题，那几条会逐条报失败）。这是有意的形态，别把失败的当成故障。

### 导出

「问题列表」右上角那颗「导出」。三档的差别只在**要不要图、给谁看、能导多少**：

| 想要什么 | 选哪一档 | 认什么范围 | 成品 |
|---|---|---|---|
| 全量清单，回 Excel 里自己加工 | 「Excel」 | **只认当前筛选**（不认勾选） | 一个表格文件，纯文字 |
| 交付甲方，含所有原始截图 | 「带图 HTML」 | **只认当前筛选**（不认勾选） | **一到多个压缩包**（按体积自动切包），每包一份网页加一批图 |
| 报送物，篇幅小、要 Word 格式 | 「Word 小批量」 | **勾了就只导勾选的**，没勾才导筛选全部 | 一个 Word 文档，含答复与截图 |

六条必须知道：

- 「带图 HTML」是**后台跑的**：提交后界面显示进度，做完自动下载，几十上百张图要跑一阵，别关页面；一次可能出好几个包，下载提示会写是几个；
- 解压后**务必用浏览器打开那个网页文件，不要用 Word 打开** —— 用 Word 打开图全是红叉（WebP 它不认）；
- 包里是**原图**不做缩略图，所以包比较大；图片文件名是一串代号、没有原始文件名，这是设计（不给外部看平台内部编号），正常；
- Word 那一档**上限一百条**，勾选超了不会自动翻页凑数，会提示你收紧筛选或改用它档；
- 导出的是**当前筛选条件下的全部问题**，跟你在第几页无关；
- 甲方与协同方三档都没有权限，连按钮都看不见 —— 要清单请让项目负责人代导。导出**不含过程附件本体**（清单里报个名字）；也不做 PDF 档 —— 要 PDF 就把带图 HTML 包用浏览器打开、打印成 PDF 即可。

### IFC 模型

上传、解析都在「IFC 配置」页（负责人 / 专业负责人 / 工程师；侧栏入口暂不开放，直达可开）。五条与直觉不同的形态：

- **一个项目同时只有一套模型**：重新上传 = **整套换掉**，旧的那套连文件一起删，没有「历史版本」可回退 —— 所以一次要把这一套的文件传齐，别只传改过的那几本；
- 一次可以**选整个文件夹**，平台按**文件名前缀**认专业 —— 前缀只在原始文件名里，所以**重传请用原始图纸目录里的文件，不要从平台下载回来再传**（那样前缀没了，解析数字会全变成 0 而状态还写着成功）；
- 解析需要这台机器装好 **Python 解析环境**（一个 Python 3.10~3.15 加一个解析包 `ifcopenshell`，装法见 [配置与部署](/guide/configuration)）；**没装也照样能传能存**，只是解析会失败并写明这台机上该执行哪条命令 —— 解析起不来不算上传失败；
- **装好 Python 环境之后不会自动补算**：之前失败的那一套，唯一的恢复办法是把原始图纸**再传一遍**；
- 「IFC 画像」页**开发中**，打开先是空的。

尺寸闸：单件 200 MB · 一次最多 60 个 · **一整套合计 8 GB**（超限整批作废，不会只留一半）。上传中可以取消；大文件进度条按**字节**走，不是按「第几个文件」。

### 项目设置（仅负责人 / 专业负责人）

三个页签，**进去先落在「项目参数」**：

| 页签 | 能做什么 | 做不了什么 |
|---|---|---|
| 项目参数 | 改项目名 · 换或撤封面 · **勾选允许 AI 做哪几件事** | **项目编号建完就不能改** |
| 成员管理 | 按姓名搜人加进来 · 改身份 · 移出 · **任命 / 降级专业负责人**（负责人与专业负责人都能做） | 负责人那一行不给移、身份只读（移交负责人得由平台管理员做）；不能把自己移走 |
| 分类体系 | 新增类目 · 改名称、缩写、顺序、颜色 | **类目不能删除，也没有「停用」开关** —— 用错了就改名复用或留着不用，历史问题的引用不断 |

三句提醒：每个项目的分类体系独立一套，新项目自带 41 项标准类目、之后自己维护；加人**输入姓名就能搜**，不用抄那串二十几位的内部编号；「允许 AI 做哪几件事」这组开关**只对新建的或从没保存过这组设置的项目自动生效** —— 保存过一次后就以库里勾的为准，AI 想干别的会被拒，要放开就在这里重新勾一次保存。

### 项目说明（全员可看，负责人 / 专业负责人可写）

三个页签：**项目概况**（整篇）· **经济技术指标**（分组表格，可增改删）· **各专业设计说明**（一张卡一篇）。

- 写设计说明的按钮叫**「添加设计说明」**：正文是建筑设计师写的，工程师和 AI 只是代为添加；
- **AI 写进去的内容一律挂「AI 写入」标记**（概况、指标表、设计说明三处都有），看见标记就知道需要核对；
- **概况只有一篇**：再点「写概况」是整篇覆盖不是追加，所以已有概况的项目那个入口会自动消失（一句话覆盖整篇太危险）；
- 说明板块**删不掉**（平台只给了「读」和「整篇覆盖」两个口子），要推倒重写就整篇覆盖上去；
- 正文显示是排版好的样子，点编辑进去是带标记的原文，直接改就行，不用装任何编辑器。

### 操作记录（项目成员都可看）

本项目的一条条流水：**谁、什么时候、对什么东西、做了什么**。

- 四个筛选都可用：按人 / 按对象类型 / 按操作 / **按来源**（人点的、系统对接、**AI 代执行**）。筛选在服务器上做，「只看 AI 改的」能翻到很久以前那几条；
- **AI 代执行的行会把两个人都写出来**：「发令：某人（由 AI 代执行）」，标记颜色也比别的重要，扫一眼就能挑出来；
- 往下拉到底有一颗「加载更多」，**没有最后一页** —— 流水接着翻比跳页符合读法；
- **没有「未读」这个概念**：这是查阅用的，不是消息中心，不会有红点；要看别人改了什么就来这页翻；
- 少数较早的记录会明写「这一条没有记下改了什么（明细是后来才开始记的）」—— **不是丢数据**，历史记录不伪造；
- 切项目会连筛选一起清空重新拉数；右上角「刷新」是手动重拉。

### 自己的账号与对接用的令牌

都在「设置」的三个页签：**个人资料**（姓名 · 头像）· **修改密码**（填旧密码；改完当前登录继续有效）· **API Token**。

令牌四条：**完整内容只在生成的那一刻显示一次**，当时不复制只能重置；**重置 = 旧的立刻失效**，一人同时只有一枚；它**只走 AI 与系统对接通道**，拿去当网页登录用会被拒；它是凭据，**不要贴在聊天、文档、代码里**，泄露了就回来点重置。

⚠️ **「联系方式」「通知设置」这两格现在没有**：平台不存邮箱电话，也没有推送 —— 要盯变化请去「操作记录」。

## 🤖 AI 接入

平台自带一层 MCP 服务，AI 客户端填一个 URL + 一枚个人令牌即可接入，17 个工具与平台接口一一对应。配置方法是 [MCP 接入](/mcp/access) 那一页的事，不是本页 —— 这里只提醒两句：**令牌直连 REST 会被拒**（自己写脚本也算），人查数据请用网页；AI 干的每一笔都会出现在「操作记录」里，带发令人。

## 📌 数据口径备忘

- **重要程度**：`1` 紧急 / `2` 普通 / `3` 轻微 / `4` 建议；不填默认「普通」；
- **状态**：只有未关闭 / 已关闭两态，没有「待审核」；
- **紧急怎么判**：十三条硬约束，围绕消防疏散、规范强制、确权、结构不可避让、拆改成本、美观外露这几类（净高不足、防火门 / 人防门 / 防火卷帘碰撞、燃气相关、管线与结构梁柱碰撞等）；图面类固定「轻微」、优化类固定「建议」；
- **分类计数天然重复计入**：四个维度都可多选，一条问题会计入多个类目，「各维度计数之和大于问题总数」是固有属性、不是数据错误 —— 首页图上找得到零条数的类目（显示为 0），报表按本项目定义的全部类目画；总数那个大数才是问题条数。

## 💬 常见问题

| 现象 | 为什么 / 怎么办 |
|---|---|
| 侧栏少了好几页 | 身份或项目参与情况决定的，不是坏了。要入口就找负责人把你加进项目、或调整你的项目内身份 |
| 切了项目，刚填的筛选条件全没了 | 故意的：那些条件属于上一个项目 |
| 按钮点不动、整栏灰着 | 抽屉里会写明原因（多半是「已关闭需先重开」或「项目已冻结」） |
| 列表「执行人」栏是空的 | 列表显示的小毛病，不是没人跟。点开抽屉看，抽屉里是准的 |
| 导出包里的图用 Word 打开全是红叉 | 那些网页只能用浏览器打开 |
| 导出只出了当前页那几条？ | 不是，导的是当前筛选下的全部；想只导勾的那几条，只有「Word 小批量」认勾选 |
| 首页和列表的数对不上 | 分组计数是「标签计数」（多挂的类目各算一次），总数大数才是问题条数 |
| 我提的问题被改过，「是谁提的」会不会变成他 | 不会，这一项永不被后续编辑覆盖 |
| 忘了密码 | 找平台管理员重置；重置会把那人所有设备下线 |
| 想删一个用错的类目 | 删不掉，也没有「停用」开关 —— 改名复用或留着不用即可 |
| 平台管理建完项目，点进去说没权限 | 正常：建项目的管理员不是该项目的成员，负责人是你建项目时指定的那一位 |
| 画像页打开是空的 | 此页开发中；模型解析成功 ≠ 画像有数 |
| 装好了 Python 环境，之前失败的那套还不动 | 环境装好后不会自动补算，把原始图纸重传一遍才会重新解析 |
| 上传模型显示失败，但我装了 Python | 先看是不是「整套只传了几本」、或文件名没有专业前缀；再确认这台机器的 Python 解析环境真的可用（含解析包那一步） |
