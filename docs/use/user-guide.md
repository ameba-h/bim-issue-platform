# 使用手册

## 页面导览

登录后侧边栏（不同角色可见项不同）：

| 页面 | 路由 | 用途 |
|---|---|---|
| 首页 | `/` | 当前项目指标卡（总数 / 未关闭 / 已关闭 / 紧急未关闭）+ 最近问题 |
| 我的项目 | `/me` | 我参与的项目（卡片含项目编号与项目 ID，点击可复制；一键直达该项目问题列表）+ 我的问题（「我提的 / 交给我的」两档） |
| 问题列表 | `/issues` | 核心工作页：筛选 / 排序 / 分页 / 批量操作 / 导出 / 详情抽屉 |
| 项目说明 | `/project` | 概况 / 经济技术指标 / 各专业设计说明（Markdown 展示，AI 写入带徽标） |
| 项目设置 | `/project-settings` | 分类体系 / 成员管理 / 项目参数（仅项目负责人与专业负责人可见） |
| 操作记录 | `/audit-logs` | 当前项目最近 20 条写操作留痕（AI 代执行的会显示发令人） |
| 平台管理 | `/admin` | 建项目 / 管账号（仅平台管理员可见） |
| 个人设置 | `/settings` | 资料 / 头像 / 改密 / API Token（侧栏无此项，从左下角头像菜单进入） |

顶栏：项目切换器（支持按项目名 / 编号搜索）· 全局搜索（`Ctrl+K`）· 用户菜单。未加入任何项目的账号只能进「个人设置」（与「平台管理」），其余入口自动隐藏。

## 角色与权限

### 两层角色体系

- **平台角色**（`users.role`，全平台一份）：`platform_admin` 平台管理员 / `user` 普通用户。平台管理员跨项目做三件事：**建项目 / 管账号 / 指派项目负责人**，不介入项目内事务、不带来任何项目内权限；
- **项目内角色**（`project_members.role`，按项目一份，一人可在不同项目担任不同角色）：

| 角色代码 | 中文名 | 一句话权限 |
|---|---|---|
| `project_owner` | 项目负责人 | 项目内最高：全部问题可增删改、可管理成员 / 分类 / 项目说明 / 参数、可任命专业负责人 |
| `civil_lead` | 土建专业负责人 | 与机电专业负责人**权限完全相等**（拆分仅为称谓标识）；项目内所有问题都能动（不限本专业）+ 全部配置权；不可任命 / 撤销专业负责人 |
| `mep_lead` | 机电专业负责人 | 同上 |
| `engineer` | 工程师 | 只能编辑**自己创建**的问题；不可删除、不可变更执行人 |
| `client` | 甲方 | 可答复、可见项目内全部问题；不可创建 / 编辑 / 删除 / 关闭 / 导出 |
| `collaborator` | 协同方 | 同甲方 |

### 权限矩阵（问题域）

| 动作 | 项目负责人 | 专业负责人 | 工程师 | 甲方 / 协同方 |
|---|---|---|---|---|
| 查看列表 / 详情 | ✅ | ✅ | ✅ | ✅ |
| 创建问题 | ✅ | ✅ | ✅ | ⛔ |
| 编辑字段 | ✅ 全部 | ✅ 全部 | ⚠️ 仅自己创建的 | ⛔ |
| **答复** | ✅ | ✅ | ✅ | ✅（唯一写入口） |
| 删除问题 | ✅ | ✅ | ⛔ | ⛔ |
| 关闭 / 重开 | ⚠️ 仅执行人 | ⚠️ 仅执行人 | ⚠️ 仅执行人 | ⛔（即便被指为执行人） |
| 变更执行人 | ✅ | ✅ | ⛔ | ⛔ |
| 批量操作 | ✅ | ✅ | ⚠️ 逐条按上述规则判定 | ⛔ |
| 导出 | ✅ | ✅ | ✅ | ⛔（服务端直接 403） |

要点：

- **关闭 / 重开只认执行人**（`executor_id`），负责人不因为是负责人就能关别人的问题；
- **已关闭的问题锁定字段编辑**（唯一例外是变更执行人 —— 这是「改执行人 → 重开 → 再改」既定流程的第一步），但**删除不受限**；
- **新建问题时执行人默认 = 创建人**（自任）；工程师离职后由负责人改派其名下问题；
- 前端按钮显隐只是体验层，**服务端逐请求独立校验**才是安全边界。

## 日常工作流

### 提问题

1. 问题列表页「新建问题」（或任意页面 `Ctrl+V` 粘贴截图自动关联当前编辑上下文）；
2. 按**六要素**描述：`楼层 → 图纸名称（版本日期）→ 位置描述 → 一句话结论 → 问题详情 → 建议`；
3. 挂分类（类型 / 专业 / 专项 / 子项四维度，可多选）、选重要程度（紧急 / 普通 / 轻微 / 建议）、填位置信息（图纸版本日期 + 轴网定位，**图纸版本为空 = 「缺位置」**，列表会有警示标记）；
4. 截图粘贴即传（前端自动压缩，最多 6 个文件）；过程附件（Word / PDF / DWG / 压缩包等，单个 ≤10 MB）原样上传、只提供下载。

### 跟进与关闭

- 任何成员可答复（答复带图走同一上传通道）；答复只增不改不删，说错了再发一条更正；
- 只有**执行人**能关闭 / 重开；
- 问题编号 4 位、项目内递增、**删除后不复用**；软删（可回溯），附件一并软删但磁盘文件保留。

### 批量操作

多选后可批量改状态 / 改分类 / 改重要程度 / 删除（按角色显隐）。批量删除前先 dry-run 预演「将删除 N 条」；提交后**逐条反馈结果**（成功 N · 失败 M · 每条原因），部分成功是正常语义。单次上限 500 条。

### 导出

| 档 | 内容 | 适用 |
|---|---|---|
| 1 · Excel | 纯文字全量清单（同步流式，秒级） | 给 Excel 继续加工 |
| 2 · 带图 HTML | 全量 + 截图原图，HTML + images 打包 ZIP（大体积自动切包） | 给甲方用浏览器看；**勿用 Word 打开**（Word 的 HTML 引擎不认 WebP） |
| 3 · Word | 带图报告（前端组装，≤100 条；勾选了行则只导勾选 ∩ 当前筛选） | 正式报送物 |

三档均跟随当前筛选条件；甲方 / 协同方无导出权。

## AI 接入

平台自带一层 MCP 服务，AI 客户端填一个 URL + 一枚个人令牌即可接入，17 个工具全部 1:1 对应本文这些 REST 端点。

要配的是 [MCP 接入](/mcp/access) 那一页，不是本页 —— **令牌直连 REST 会被拒**（`403 TOKEN_AI_CHANNEL_ONLY`，自己写脚本也算），人查数据请用网页。工具清单与逐工具的行为差异见 [工具清单](/mcp/tools)。

## 数据口径备忘

- **重要程度**：`1` 紧急 / `2` 普通 / `3` 轻微 / `4` 建议（接口与界面均为整数）；
- **状态**：`open` 未关闭 / `closed` 已关闭；
- **紧急判定参考**（紧急 = 消防疏散 / 规范强制 / 确权 / 结构不可避让 / 拆改成本 / 美观外露）：净高不足、防火门 / 人防门 / 防火卷帘碰撞、燃气相关、预留预埋、管线与结构梁柱基础碰撞、车道车位确权、外露管线等；图面类固定 = 轻微、优化类固定 = 建议；
- **分类计数存在重复计入**：四维度全部可多选，一条问题会计入多个类目，「各维度计数之和 > 问题总数」是固有属性，不是数据错误。
